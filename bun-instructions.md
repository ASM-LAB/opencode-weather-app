# Directrices del Proyecto

## Comandos Principales
- **Instalar dependencias:** `bun install`
- **Ejecutar en desarrollo:** `bun dev` / `bun start`
- **Ejecutar pruebas:** `bun test`
- **Linter / Formato:** `bun run lint`

## Convenciones de Código y Estilo
- Usar **TypeScript** con tipado estricto.
- Respeta la arquitectura de carpetas del proyecto.
- Escribir los comentarios y mensajes de commit en español.
- Mantener las funciones pequeñas y con una única responsabilidad.

## Notas y Restricciones
- No modificar directamente archivos generados o en `/dist`.
- Mantener las variables de entorno documentadas en `.env.example`.
